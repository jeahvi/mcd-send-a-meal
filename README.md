# MCD Send-a-Meal · 麦麦代送

> **「妈，我给你点了份薯条，趁热吃。」**
>
> 用麦当劳 MCP，给不在身边的人点一份麦当劳。

一个基于 **麦当劳中国 MCP Server** 的点餐 Skill：帮你把一份热薯条，送到另一个城市、另一个人手里。

---

## 为什么做这个

麦当劳点餐工具已经很多了，但它们几乎都在解决同一件事：**帮你自己省钱、帮你自己算热量**。

可麦当劳最常被用来做的事，其实是**惦记一个人**。

- 在外地工作，想给爸妈点什么，但不知道他们那边附近哪家店能送、现在开着没有
- 异地恋，想说句"记得吃饭"，比转账更像话
- 室友加班到半夜，想给他点一份，但不好意思开口问"你要吃什么"

**麦麦代送把这件麻烦事变成一句话。** 它不是给自己点餐，它是**给别人**点餐——这是本 Skill 与所有同类项目最根本的区别。

## 它做什么

```
> 我妈在杭州，胃不好不太能吃辣，帮我点一份送到她那儿，别太油

🍟 已定位「杭州市西湖区文三路」
   附近可配送门店 3 家，已选最近一家（预计 28 分钟送达）
   已按「不吃辣 / 少油」筛选，避开 2 款餐品

   推荐搭配：板烧鸡腿堡（不辣）+ 玉米杯 + 热红茶
   合计 ¥34.00（已自动用券减 ¥5）

   给妈妈的话：
   「天冷了，吃点热的。别省着。」

   [ 确认下单 ]   [ 换一份 ]
```

下单后生成一张**心意卡片**（可截图分享到微信/朋友圈），再走 MCP 完成支付。

## 目标用户

| 人群 | 场景 |
|---|---|
| 异地工作者 | 给老家父母点一份，代替"我很好"三个字 |
| 异地恋情侣 | 想表达关心，又不想显得刻意 |
| 室友 / 同事 | 对方加班，默默点一份记他账上 |
| 学生 | 给同城异校的朋友一个惊喜 |

## 安装

> 前置条件：需要麦当劳中国的 MCP Token（申请地址：https://open.mcd.cn/mcp）

```bash
git clone https://github.com/jeahvi/mcd-send-a-meal.git
cd mcd-send-a-meal
npm install
cp .env.example .env.local     # 填入你的 MCD_MCP_TOKEN
```

## 配置

`.env.local`（**不要提交到 Git**）：

```ini
MCD_MCP_TOKEN=your_token_here
```

MCP 接入配置见 [`mcp-config.example.json`](./mcp-config.example.json) 与 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md)。

## 使用示例

```bash
# 给指定的人点一份（会先给出方案，确认后才下单）
npm run send -- --to "妈" --city 杭州 --address "西湖区文三路XX号" \
              --note "不吃辣，少油" --message "天冷了，吃点热的"

# 只推荐不下单（dry-run，安全预览）
npm run send -- --to "妈" --city 杭州 --dry-run
```

作为 Agent Skill 使用：

```
/send-a-meal 帮我给在杭州的妈妈点一份，她不吃辣
```

## 安全设计

本项目把**下单视为不可逆操作**，因此：

- **默认 dry-run**：不带 `--confirm` 不会真正下单，只输出方案与价格
- **两段式确认**：先展示门店、餐品、实付金额、给对方的留言，用户确认后才调用 `create-order`
- **Token 只走环境变量**：仓库内不含任何真实凭证，配置文件仅保留占位符
- **地址最小化**：仅调用麦当劳 MCP 地址接口，不落库、不外发
