# 演示脚本 · MCD Send-a-Meal

> 目标：30 秒内让人记住这个项目，并愿意点 Star。

## 一、一句话开场（录屏旁白）

> "麦当劳的点餐工具都在教你省钱，但麦当劳最常被用来做的事，其实是惦记一个人。"

## 二、演示步骤

### 步骤 1 · 展示痛点（10 秒）

```
> 我妈在杭州，胃不好不能吃辣，想给她点份麦当劳，但不知道她那边哪家店能送
```

旁白：*「异地给家人点餐，难的不是点，是你根本不知道对方那边什么情况。」*

### 步骤 2 · 一句话搞定（10 秒）

```bash
npm run send -- --to 妈 --city 杭州 --note "不吃辣，少油"
```

### 步骤 3 · 确认下单（5 秒）

```bash
npm run send -- --to 妈 --city 杭州 --address "西湖区文三路XX号" --confirm
```
→ 调用 `create-order`，返回支付链接。

### 步骤 4 · 收尾（5 秒）

旁白：*「她收到的时候，会看到这句话。」*

## 三、录制要点

- 全程真实调用 MCP，**不要剪辑掉门店/价格的真实数据**
- 卡片出现时停 2 秒，让观众看清对齐和文案
- dry-run 到 confirm 的两段式确认**必须展示**，这是安全设计亮点
- 结尾加一句："项目开源，欢迎试用，觉得有意思点个 Star"

## 四、发布文案（社区发帖用）

**标题**：我给在杭州的妈妈写了个点麦当劳的工具

**正文**：
麦当劳的点餐 AI 已经很多了，清一色在帮你省钱、算热量。但我异地工作三年，最想用的功能其实是——给我妈点一份，别让她老凑合。

所以我做了麦麦代送。一句话，它会自己找到我妈那边能配送的门店，按"不吃辣、胃不好"筛掉不能吃的，算好用券后的价格，然后生成一张卡片，让我把想说的话写进去。

技术上用了麦当劳 MCP 的 delivery-create-address（这是"代送"和普通点餐最本质的区别——你得先有对方的地址）、list-nutrition-foods（拿营养数据做忌口过滤）、calculate-price、create-order。为了安全，下单前一定有一步确认，不会 AI 自作主张给你花钱。

开源在 GitHub，欢迎拍砖。
